# Growfinix Task 1 - Automated Weekly Reporting Pipeline

## Objective
To automate the generation of a weekly business report using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Workflow
1. Collect weekly business data
2. Calculate sales and customer statistics
3. Generate sales and customer charts
4. Generate a PDF weekly report
5. Prepare the report for email delivery

## Key Metrics
- Total Sales
- Average Daily Sales
- Total Customers
- Average Daily Customers
- Best Sales Day
- Highest Sales

## Output
An automated PDF weekly business report containing summary statistics and charts.

Completed successfully as part of the Growfinix Internship.
