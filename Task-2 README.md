# Task 2 - Geospatial Analytics for Logistics

## Objective
Analyze delivery locations using geospatial analytics and identify delivery bottlenecks and clusters.

## Tools Used
- Python
- Pandas
- Folium
- GeoPandas
- Scikit-learn
- KMeans Clustering

## Work Done
1. Created logistics delivery data with latitude and longitude.
2. Visualized warehouse and delivery locations using Folium.
3. Created delivery route visualization.
4. Identified bottleneck deliveries based on delivery time.
5. Applied KMeans clustering to group delivery locations.
6. Created an interactive cluster map.

## Bottleneck Analysis
Deliveries taking more than 50 minutes were identified as bottlenecks.

## Clustering
Delivery locations were divided into 2 clusters using KMeans.

## Conclusion
Geospatial analytics helps identify delivery bottlenecks, understand delivery location clusters, and support better logistics planning.
